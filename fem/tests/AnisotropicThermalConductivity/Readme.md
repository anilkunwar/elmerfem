The computation of heat transfer (steady state) in screw dislocation within Cu6Sn5 IMC unit cube.

k_{ij} = k_{ideal}[[ 1 0 Ay] [0 1 -Ax] [Ay -Ax 1+A]]

where, A = b^2/(4*pi^2(x^2+y^2))

b = burgers vector

x,y = cartesian coordinates

k_{ideal} = thermal conductivity of crystal without defect

k_{ij} = direction dependent thermal conductivity
